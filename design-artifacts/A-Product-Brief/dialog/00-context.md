## Working Relationship Context

### Stakes
**Level:** departmental

**What this means:**
Departmental/organizational stakes — comprehensive justification and evidence-based reasoning expected. Decisions affect multiple stakeholder groups (admin, teachers, students, lab ops, researchers) who depend on fair, auditable access to a scarce shared resource.

**Stakeholders (if applicable):**
- Academic Administration — fair, policy-aligned governance and auditability, no financial chargebacks/billing
- Teachers — absolute guarantee scheduled class GPU capacity is protected from general use
- Students — transparency, clear denial reasons (rule / quota / unavailability / reservation conflict)
- Lab Operators — real-time operational visibility into machine health, occupancy, failures
- Privileged Users / Researchers — controlled permission paths for high-VRAM and distributed-training jobs

**Political Sensitivities (if applicable):**
- GPU resource scarcity
- Friction between ad-hoc student access and strict class reservation windows
- Eliminating current informal/manual coordination
